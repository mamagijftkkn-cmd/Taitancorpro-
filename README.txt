TITANCORE PRO — INTERNATIONAL WEBSITE
1) Extract this ZIP.
2) Upload the extracted folder contents to Cloudflare Workers & Pages > Create application > Pages > Upload assets (or deploy a new version of your existing Pages project).
3) Make sure index.html is at the project root and the assets folder sits beside it.
4) Deploy, then open the generated *.pages.dev or workers.dev URL.
